## 功能

- **双语文档**：保留原页数与分栏，正文优先11磅并按原页适配；图名、表格与脚注分别排版。原文和译文保留超链接。
- **完整性检查**：逐句建立翻译记录，识别正文、参考文献、模型编号和原生公式。检查实际导出PDF，保存未解决的位置及处理结果。
- **轻量阅读**：逐页显示译文预览，支持缩放、双栏同步、鼠标中键拖动与专注阅读。
- **文献研读与批注**：独立阅读视图、笔记、批注、页面编排和导出。
- **专业知识**：词典、语法、时态语态、例句、专业解释、AI图文及网页来源内容；已有图文可缓存，图片可放大缩小。在线图像生成需要相应服务与额度。
- **科研工作台与账户**：保存研究项目与资料。本地访客可以阅读和使用本地模型；账户中心提供账户管理与正式安装包下载。

## 使用与维护

打开文档，选择本地或可用的在线通道，选择目标语言后开始。完成后可保存中文译文、双语PDF和逐句核查资料。专注阅读隐藏底部任务栏；图片查看器支持完整显示、缩放与拖动。

客户端与安装包提供相同的冻结程序、模型和依赖，并附文件哈希清单。自动检查验证结构与内容清单，不能认证每句话的科学含义，也不能保证任意未来PDF无误。图像内部文字与扫描质量仍需核对。本轮没有新增在线GPT生图、付费知识生成或邮件发送测试。
