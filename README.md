# 小奕译读

面向科研文献的 Windows 双语阅读、PDF 翻译与知识整理客户端。

当前版本 **1.44.3**，完善引用恢复、跨文档经验复用与图标。实际安装后的客户端独立完成 **14/14页、5/5页**，第二篇实际复用1次已验证经验。测试期间未修改业务代码或人工补修。详见[本版实测](guides/RELEASE-1.44.3.md)。

## 功能

- **双语文档**：导入 PDF、Word 和图片；保留标题、作者、原文分栏、正文、图表、图注与页脚的逻辑分区，原译文对照。参考文献的文章条目保持原文。
- **内置补修**：局部错误按段落 ID 处理；每段最多追加两轮，反馈拒绝草稿和具体问题，保护数字、链接和公式；成功结果缓存后继续处理独立内容。
- **跨文档经验**：本机保存修复行动和结果；经两篇不同文档的真实 PDF 验证后，符合条件的经验参与后续选择。界面可查看、停用或撤销。
- **阅读与链接**：缩放、同步滚动、中键拖动、专注阅读；保留外链和页内跳转。
- **文献研读**：阅读器、文献助手、选段翻译、问答、笔记和历史成果。
- **文本翻译**：自动识别语言、术语配置与取消，新输入优先。
- **专业知识**：词性、释义、搭配、适用的语法分析及例句；专业说明、示意图、网页图文分别保存，图片支持缩放。
- **批注与页面编排**：文字标记、笔记、页面排序、旋转及导出。
- **科研工作台与账户**：组织文献和资料，保存研究流程；账户中心管理已开通的个人资料、设备和服务权限。
- **离线与网络适配**：内含 Qwen3 4B 本地通道；在线服务跟随当前 Windows 系统网络和 PAC，不绑定代理软件或端口。
