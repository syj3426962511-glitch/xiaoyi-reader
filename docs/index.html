BEFORE YOU START

关于公开范围与使用。

完整使用指南 ↗
可以直接下载客户端或核心源码吗？

公开项目介绍、实机截图、核查结果与使用资料。核心源码、私人配置和论文全文不公开。1.43.26安装包已完成发布校验，当前账户下载入口处于维护中；需要使用或交流，请联系3426962511@qq.com。

这个网页能上传并翻译PDF吗？

当前是静态展示网页，不提供文档上传、账号登录或在线翻译。在线与本地翻译入口位于Windows客户端中。

“自适应”会自行训练模型或修改程序吗？

它保存问题记录、成功译文缓存并复用受约束的修复规则。新类型问题仍需完善算法与复验，不能称为云模型自行训练或任意自我改写。

为什么不承诺全新20页文档的完成时间？

页数之外，文字密度、字体、表格、网络和新句数量都会影响总时长。这里公布的是特定样本的混合缓存记录，没有受控的全新20页首译基准。
