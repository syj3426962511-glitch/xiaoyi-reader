# 小奕译读使用指南

Windows 64 位客户端。安装包包含程序、视觉模型、离线 Qwen3 4B、CPU 运行库与可用的显卡后端；可自定义安装路径。

1. 安装后打开“小奕译读.exe”。升级沿用当前个人配置；首次使用默认“使用自己的 API”。
2. 在顶部选择翻译通道和目标语言。在线通道需要已开通的个人 API 或账户共享权限；本地 Qwen 使用安装包内的模型。
3. 打开 PDF。文档按原文标题、作者、正文栏、图表、图注和页脚等分区识别与重新排版。原始文件保留。
4. 任务详情显示执行阶段、总用时、处理页数和校验页数；检查提示与已完成页分开显示。
5. 导出译文或双语 PDF。科学术语、公式解释和结论请结合原文核读。

双语阅读支持同步滚动、缩放、中键拖动和原文链接。文献研读提供阅读器、助手和选段翻译；批注与笔记保存在本机。专业知识提供词典、专业说明、示意图及网页图文，图片支持放大与拖动。科研工作台组织资料、历史成果与研究任务。

正文基准 10 磅，图注与出版信息使用独立样式。密集区块采用弹性行距及局部字号调整，标题保留更大字号；实际位置偏差单独列入核查。参考文献处理按界面选择保留或翻译。

关闭主窗口使用 Yes / No 确认。新版本保留本机加密配置；Windows 账号加密资料在换电脑时需使用产品支持的安全迁移流程。公开安装包不包含作者私人密钥。
