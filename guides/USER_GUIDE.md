# 使用指南

## 获得程序

当前公开仓库提供介绍、截图与结果摘要。核心代码、安装包和模型不在仓库中；如有需要，请联系 **[3426962511@qq.com](mailto:3426962511@qq.com)**，说明使用或学习目的。

客户端面向 Windows 桌面。获得完整程序后按随包说明安装或启动；请保留同一版本所需依赖，不要只复制单个 exe。实际环境要求、可用模型和服务权限以获得的版本说明为准。本仓库的网页版只是展示页面，不是网页翻译器。

## 一次完整的文献阅读

1. 选择可用翻译通道。在线模式确认网络与服务权限；本地模式确认资源已经准备好。
2. 打开原文，确认源语言与目标语言，保留原始文件。
3. 查看句段、排版和显示进度，等待目标页面出现；区分完成、处理中、部分完成和失败。
4. 对照原文核读译文；重点检查术语、数据、公式、图名和表格。
5. 使用中键移动页面，必要时 F11 专注阅读；在链接处点击可回到来源。
6. 在三栏研读中查看原文、助手解释和选段译文；按习惯调整栏宽并保存。
7. 查阅专业知识，区分词典出处、模型解释和人工构造例句。点击图文图片查看完整尺寸。
8. 全文完成后导出译文、双语对照与需要的核查资料。

## 中断与恢复

先查看任务详情中的具体阶段和错误，不把空白目标页认作成功。已有成功缓存可以复用，但通道、文档与适用规则变化可能导致重新处理。不要删除仍在运行任务的中间文件，也不要把旧任务的完成状态套到新文件上。

## 图片操作

图片窗口先完整适应窗口；滚轮或加减按钮缩放，拖动查看，完整图片按钮或双击恢复。公开项目网页也提供图片查看器：点击截图后可缩放、拖动，按 Escape 关闭。

## 反馈格式

提供版本号、Windows 版本、文件类型与页数、所选通道、复现步骤、具体页码，以及去掉账号与密钥的截图。涉及论文或其他受限文件时，先确认有分享权限；不要将密钥、账户信息或未获许可的全文直接贴在公开 Issue 中。
