# 小奕译读 1.43.28

面向科研文献的 Windows 双语阅读、PDF 翻译与知识整理客户端。

服务来源默认“作者共享云端”；个人 API 配置和所选模型保留，之后的手动选择按页面保存。个人配置在本机加密，工厂安装包包含程序、模型和必要依赖。

## 本版修复

补齐跨版本个人 API 继承和安装包的简繁转换原生依赖，已有配置优先；纠正原生上下标、希腊字母前缀、图号范围和文字边界运输；按源 PDF 字形分开双栏图注，按原坐标归并混合字体公式并恢复原有换行；保护邮箱和完整链接。普通正文即使没有公式或链接，也进入受约束补译，避免遗漏英文从句。

共用生产入口按对象记录问题并继续处理其余内容，输出前对未回填、锚点、链接和排版问题做有限两轮自动修复，再检查实际 PDF。通过复检的结构策略可供类似段落复用，失败策略隔离。已有译文和原文件保留。

## 功能

- **双语文档**：PDF、Word 和图片导入，原译文并排；逐页预览、缩放、同步滚动与保存。正文优先 11 磅，表格、图名和脚注分别适配，保持原页数。
- **阅读交互**：按住鼠标中键拖动上下左右位置，专注阅读隐藏底部任务区；原文与译文保留外部链接和页内跳转。
- **文献研读与批注**：独立阅读视图，支持选段、笔记、标记、历史记录、页面编排与导出。
- **文本翻译**：自动识别原文语言，输入后分段更新，切换模型与术语后重新处理；旧请求结果不会覆盖新输入。
- **专业知识与图文**：词典、适用的语法/时态/语态与双语例句，专业说明与示意内容分别保存；AI 图文和网页来源独立缓存，图片可完整查看、缩放和拖动。
- **科研工作台与账户**：组织项目、资料与任务；账户中心管理资料、设备和已开通权限。本地模式使用内置 Qwen3 4B。
- **网络适配**：读取当前 Windows 系统网络与 PAC，需要时使用系统代理；本机模型直连，不绑定代理软件、端口、订阅或节点。

## 使用

打开文件，选择所需通道和目标语言后开始。作者共享云端需要已登录账户及对应共享权限；使用自己的 API 可在本机填写平台配置；本地 Qwen3 4B 可在资源完备时离线运行。已有任务保留开始时选择的服务来源。

完成状态依据应译区域回填和实际 PDF 核验。原生公式、参考文献、出版信息及部分图内标签可原样保留，核对提示另列；自动检查覆盖结构和完整性，科学语义仍需结合原文核读。两轮仍无法可靠恢复时保留失败位置与断点。
